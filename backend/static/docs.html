Prueba la API desde el navegador

Cada bloque de esta página es una operación del servidor. Ábrelo, llena los datos y pulsa Execute: la respuesta aparece justo debajo.

  1. Pide un código

    En /auth/request-code escribe tu número. La respuesta trae el código en dev_code.

  2. Entra

    En /auth/verify envía el número y el código. Copia el access_token sin comillas.

  3. Autoriza

    Pulsa el botón Authorize, pega el token y confirma. El botón se pone verde.

  4. Usa el resto

    Las operaciones con candado ya responden a nombre de ese número.

Qué significa cada respuesta

  • 200Todo salió bien.
  • 201Se creó o se guardó lo que enviaste.
  • 401Falta el token o ya venció. Repite los pasos 1 a 3.
  • 403Esa persona no te ha dado permiso, o te lo retiró.
  • 404No existe: el número no tiene cuenta o aún no hay datos.
  • 409La solicitud ya está en otro estado.
  • 422Un dato tiene mal formato, por ejemplo el número sin +.
  • 429Demasiados intentos. Espera un minuto.

Operaciones

Verde guarda o cambia algo, azul solo consulta, rojo borra. El candado indica que la operación necesita token.
